# ГОЛЕАДОР

Оригінальна 3D-футбольна гра просто в браузері: HTML + JavaScript + [three.js](https://threejs.org) (бібліотека лежить у `lib/`, інтернет для гри не потрібен).

Гравці — реалістичні 3D-моделі людей зі скелетом і анімаціями від [Quaternius](https://quaternius.com) (ліцензія CC0, див. `assets/LICENSE.txt`); форма команд і номери малюються в грі.

Запуск локально: файли моделей вантажаться з папки `assets/`, тому гру треба відкривати через вебсервер (наприклад, `python3 -m http.server` у папці гри й адреса http://localhost:8000).

**Як запустити:** відкрийте `index.html` у сучасному браузері (Chrome, Edge, Safari, Firefox).

## Що є
- 3D-стадіон: газон із покосом, тіні від прожекторів, трибуни з уболівальниками, що підстрибують після гола, LED-борти з рекламою, що біжить
- Об'ємні гравці з анімацією бігу, удару, удару головою, підкату, падіння, стрибка воротаря й святкування
- Фізика м'яча: опір повітря, закручені удари (ефект Магнуса), відскоки, штанги й поперечина, сітка, що прогинається
- Реалістичний дриблінг: м'яч не «приклеєний», гравець веде його дотиками; на прискоренні м'яч відкочується далі
- Інерція гравців: розгін, гальмування, на швидкості важче різко повернути
- 7 на 7, AI-суперник із трьома рівнями складності, кутові, вкидання, удари від воріт
- Три камери: трансляція, широкий план, за гравцем
- Сенсорне керування для телефона
- Режими: товариський матч, турнір (8 клубів, сітка на вибування, пенальті) і кар'єра (сезон ліги з 10 клубів, таблиця, новини, мета від правління, прогрес зберігається в браузері)
- 10 вигаданих клубів у кольорах відомих європейських команд, у кожного свій склад з іменами

## Керування
| Дія | Клавіші |
|---|---|
| Бігти | Стрілки або WASD |
| Прискорення | Shift |
| Пас / змінити гравця | Пробіл або J |
| Удар (затисніть для сили) / відбір | K або X |
| Камера | C |
| Пауза | P або Esc |
| Звук | M |

На телефоні гра відкривається на весь екран (кнопка ⛶ — увімкнути/вимкнути). Джойстик з'являється там, де ви торкнулися лівої половини екрана; якщо потягнути палець за межу кола — гравець прискорюється. Якщо тримати телефон вертикально, камера стає за спину гравця.
