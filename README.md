# ГОЛЕАДОР

Оригінальна футбольна гра просто в браузері: HTML + JavaScript + canvas, без жодних залежностей.

**Як запустити:** відкрийте `index.html` у будь-якому сучасному браузері (Chrome, Edge, Safari, Firefox).

## Що є
- Поле з покосом трави, розміткою, воротами з сіткою, рекламними бортами й трибунами
- 7 на 7: воротар, захисники, півзахисники, нападник
- Фізика м'яча: висота, відскоки, тертя, штанги й поперечина
- Пас, удар із силою (затиснути клавішу), відбір, зміна гравця
- AI-суперник із трьома рівнями складності, AI-воротарі
- Табло з рахунком і часом, міні-карта, кутові, вкидання, удари від воріт
- Звуки (удар, свисток, трибуни) і сенсорне керування для телефона

## Керування
| Дія | Клавіші |
|---|---|
| Бігти | Стрілки або WASD |
| Прискорення | Shift |
| Пас / змінити гравця | Пробіл або J |
| Удар (затисніть для сили) / відбір | K або X |
| Пауза | P або Esc |
| Звук | M |
